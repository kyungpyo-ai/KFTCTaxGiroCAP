부록: 원캡(KFTCOneCAP) 자체 정의 오류코드

본문 §3장(응답 코드)은 인터넷지로/KFTCVAN이 내려주는 코드만 정의하고 있습니다. 원캡이 카드 리딩·
사용자 취소·Timeout·리더기 및 VAN DLL 연동 오류 등 자체 판단으로 거래를 실패시키는 경우를 위해,
개발 과정에서 아래 3종 접두 코드 체계를 신설했습니다(#7 응답 코드 위치에 그대로 실림). 키오스크(POS)
개발 시 #7 응답 코드를 처리하실 때 본문 §3장의 코드와 함께 참고해 주시기 바랍니다.

────────────────────────────────────────────────────────────
표 1. E — 원캡 자체 판단 + 전문 오류
────────────────────────────────────────────────────────────
코드	의미
E01	사용자 취소
E02	Timeout(카드 입력 대기 또는 카드 비밀번호 입력 대기 중 시간 초과)
E03	리더기 설정 화면 사용 중(설정 화면이 열려 있어 카드 리딩을 시도하지 않고 거부)
E04	리더기 미설정(사용 가능한 리더기 없음)
E05	리더기 무결성 체크 실패
E40	요청 전문 길이 불일치
E41	알 수 없는 거래 구분 코드(#4)
E99	원캡 내부 오류(그 외 처리 중 예외)

────────────────────────────────────────────────────────────
표 2. R — 리더기 관련 오류
────────────────────────────────────────────────────────────
코드	의미
R00 ~ R23	리더기가 정상 응답했으나 업무 응답코드가 실패(리더기 SPEC의 2자리 업무 응답코드 00~23을 그대로 "R"+코드로 표기, 00/07/12 제외)
R20	리더기 포트가 열려 있지 않은 상태에서 명령 시도
R21	리더기 명령 송신 실패
R22	리더기가 다른 명령 처리 중(BUSY)
R23	지정한 COM 포트를 찾을 수 없음
R24	리더기 포트 오픈 실패
R25	허용되지 않는 명령
R27	리더기 응답 수신 중 통신 오류
R28	그 외 리더기 DLL 연동 오류(위 항목에 해당하지 않는 경우)
R29	리더기 실패 원인을 특정할 수 없는 경우(리더기 무응답, 카드 데이터 없음, 재시도 횟수 초과 등)

────────────────────────────────────────────────────────────
표 3. D — VAN DLL(KFTC_GIRO.dll) 연동 오류
────────────────────────────────────────────────────────────
코드	의미
D01	VAN DLL 로드 실패
D02	VAN DLL 호출 자체 실패(서버 거절과는 다른, 통신 실패)

────────────────────────────────────────────────────────────
참고
────────────────────────────────────────────────────────────
- 승인(정상) 및 VAN 서버 거절 응답코드는 원캡이 자체적으로 만들지 않고, VAN이 실제로 내려준 값을
  그대로 전달합니다. 위 3개 표는 원캡이 VAN 요청 전 단계에서 스스로 실패를 판단해 만드는 코드만
  다룹니다.
- 위 코드는 본문 §3장이 이미 사용 중인 접두 문자(M, V 등)와 겹치지 않도록 E/R/D 3종만 사용합니다.
